# House Price Prediction Using Statistical Analysis

A data-science mini project: analyse 1,000 house records with statistics, probability, correlation and
regression, implement the regression mathematics from scratch in NumPy, and predict house prices (Rs lakhs).

> **About the data:** the dataset is **synthetic**. It is generated by [`src/generate_data.py`](src/generate_data.py)
> (seed 42) from a feature-based pricing rule plus 6% noise, with a few duplicates and missing values injected on
> purpose so the cleaning step has work to do. The results therefore demonstrate the methods; they do not describe a
> real market. To use real data, replace `data/house_prices_raw.csv` with a CSV that has the same columns and run
> `python src/run_all.py`.

## What is covered (course tasks 1-8)

| Task | Where | Highlights |
|---|---|---|
| 1. Preprocessing | `src/preprocessing.py` | 12 duplicates removed, 30 missing values imputed, IQR outlier check, 70/15/15 split |
| 2. Descriptive and inferential statistics | `src/statistics_analysis.py` | mean/median/mode/variance/SD, simple random and stratified sampling, CLT, Welch t-test (Urban vs Suburban), ANOVA |
| 3. Probability | `src/probability_analysis.py` | P(price > Rs 100 lakhs), P(high \| area > 1,500 sq ft), Bayes' theorem, law of large numbers |
| 4. Correlation | `src/correlation_regression.py` | Pearson and Spearman matrices, strongest factors for price |
| 5. Regression | `src/correlation_regression.py` | simple (Area) and multiple linear regression with OLS table (SE, t, p, CI, VIF) |
| 6. Linear algebra | `src/numpy_math.py` | vectors, matrices, dot product, XᵀX, normal equation |
| 7. Calculus and optimisation | `src/numpy_math.py` | cost function, gradient, gradient descent, learning-rate study |
| 8. Evaluation and residuals | `src/modeling.py` | MAE, MSE, RMSE, R², MAPE, residual plots, over/under-estimation by price band and location |

## Results (test set, 150 houses)

| Model | MAE (lakhs) | RMSE (lakhs) | R² |
|---|---|---|---|
| Mean baseline | 19.62 | 25.00 | 0.000 |
| Simple linear regression (Area) | 14.48 | 18.47 | 0.454 |
| **Multiple linear regression** (selected on validation) | **5.00** | **6.32** | **0.936** |
| Random forest (tuned) | 6.87 | 9.34 | 0.861 |
| Gradient boosting (tuned) | 5.76 | 7.25 | 0.916 |

Gradient descent in NumPy reaches the normal-equation solution (largest weight difference 6e-7).
Linear regression wins here because the synthetic prices follow a linear rule; on real data, tree ensembles may do better.

## Prototype: House Price Estimator

[`House Price Estimator.html`](<House Price Estimator.html>) is a single-page web app. Enter a house's details and it shows the price
predicted by the multiple linear regression model (coefficients copied from `results/results.json`), a range of one typical
error, and how much each feature adds or subtracts. It needs no server: open the file in a browser, or turn on
**GitHub Pages** (Settings > Pages > Deploy from branch > `main`, folder `/ (root)`); the page is then served at `https://<username>.github.io/<repo-name>/House%20Price%20Estimator.html`.

## Project structure

```
data/                 raw (1,012 rows) and cleaned (1,000 rows) CSV files
House Price Estimator.html   prototype web page (single file)
src/                  one module per task + run_all.py
tests/                pytest checks (metrics, gradient, gradient descent, OLS, data)
results/              results.json, tables/*.csv, figures/*.png (14 figures)
reports/              project report (.docx and .pdf) and presentation (.pptx and .pdf)
report_tools/         scripts that build the report and slides from results.json
```

## How to run

```bash
pip install -r requirements.txt
python src/run_all.py          # whole analysis: tables, figures, results/results.json
python -m pytest tests         # 5 tests
python report_tools/build_report.py   # report (.docx, plus .pdf if LibreOffice is installed)
python report_tools/build_slides.py   # presentation (.pptx)
```

Everything is seeded (`SEED = 42` in `src/config.py`), so results are identical on every run.
